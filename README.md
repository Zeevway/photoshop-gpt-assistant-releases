# GPT 图像助手 · 安装包与更新

本仓库用于公开分发 GPT 图像助手的 Windows 安装包与更新说明。开发源码保存在独立私密仓库，本仓库不包含开发历史。安装包包含插件运行所需的客户端代码。

[下载最新安装包](https://github.com/Zeevway/photoshop-gpt-assistant-releases/releases/latest)

0.5.5 界面分为 **运行、key、设置**：运行页处理任务，key 管理连接与对话模型，设置管理生图、高清处理、更新和反馈。整体界面适配窄面板与小窗口；设置页支持主动向作者提交反馈，可选脱敏诊断，并保留复制备用。提交前请检查预览，提交成功仅表示服务已接受，不等于收件箱回执。

安装条件：Windows、Photoshop 2026 / 27.0 或以上，以及 Creative Cloud Desktop 提供的 Adobe UPIA 安装组件。PS 2018 不兼容。先保存文档并退出 Photoshop，再运行 Setup.exe；系统管理员权限提示需要确认。安装器目前未签署商业代码签名证书。

0.5.4 起可在 **设置 → 插件更新** 检查后续正式版本，0.5.0–0.5.3 的入口位于 key 页。下载进度以百分比显示；安装包通过大小与 SHA-256 校验后才启动安装器。打开安装器后仍须退出 PS；如提示正在运行，退出后点击“重试”。不会强制关闭 PS。低于 0.5.0 的旧版需要先手动安装一次支持更新的版本。

完整安装器已包括插件、基础本机图片引擎与保真模型，无需单独安装 Node.js 或 UXP 开发工具；不包含 Photoshop、Creative Cloud 或可选大型模型。本机升级保留已有 Key 与模型配置。其他电脑仍需自行配置 AI API Key，另行安装所需的可选增强、人脸修复模型与权重；安装包不会复制本机外部模型配置。更新不需要 GitHub 登录，不使用 AI Key，也不要求本机图片引擎在线。

插件内提交反馈需能访问 Google Apps Script 及其响应服务；网络不可达时可复制反馈备用。反馈只在用户点击提交后发送，可不附带诊断，不自动上传草稿、图片或聊天记录。

0.5.5 的 606 项自动测试、32 项安装器检查及浏览器回归通过，本机安装与文件一致性已核验；Photoshop 原生界面、剪贴板及反馈提交的宿主验收尚未完成，邮箱送达未核对。

安装包中的第三方组件许可证随包附带。用户 Key、聊天记录、本机模型配置及用户图片不会作为发布内容上传。GitHub 自动提供的 Source code 压缩包仅含本仓库的说明文件，请下载以 `-Setup.exe` 结尾的安装器。
